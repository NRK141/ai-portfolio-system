# Outputs

This folder is intentionally kept in the repository, but generated output files are ignored by Git.

When the backtester runs, it will create local files such as:

- `outputs/reports/portfolio_backtest_report.pdf`
- `outputs/charts/equity_curve.png`
- `outputs/charts/drawdown.png`
- `outputs/csv/portfolio_equity.csv`
- `outputs/csv/strategy_comparison.csv`

These files are stored locally and should not be committed to GitHub.
